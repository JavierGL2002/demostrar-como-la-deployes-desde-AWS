# Portafolio personal de Javier

Página web estática en español, hecha con HTML y CSS. No requiere instalación ni dependencias.

## Verla en tu computadora

Abre `index.html` en un navegador.

## Personalizar

- En `index.html`, reemplaza `hola@ejemplo.com` con tu correo real.
- Actualiza los textos de presentación con la información que quieras compartir.
- Los proyectos se pueden agregar duplicando la estructura de `.project-card`.

## Publicarla con GitHub Pages

Después de subir estos archivos a un repositorio de GitHub, abre **Settings → Pages** y configura la publicación desde la rama `main` y la carpeta `/ (root)`.
